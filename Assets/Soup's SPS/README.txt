# Steps to install:

1. Drag the SPS Prefab into the root of your avatar

2. You can customize the SPS menu location using VRCFury's Move Menu script.

3. Have fun~


# Testing Lollies:

The testing lollies appear in `SPS/Lollie` by default. These depend on Poiyomi, if you do not wish to include poiyomi, set them as standard shader (nasty looking), or unpack the prefab and delete them.

Notice: you cannot trigger SPS's Auto mode using your own plug.
