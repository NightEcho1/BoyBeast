REFERENCE LAMP - photo-based decorative prop

Use ReferenceLamp.prefab. Drag it into your Unity scene at scale (1,1,1).
ReferenceLamp_Demo.unity provides a camera and simple studio lighting.

Dimensions: approximately 34 cm tall, 10.3 cm wide at the base.
Materials: Unity built-in Standard shader, three materials, 2048px textures.
The narrow green base ring uses emission. It does not cast real-time light.
The prefab contains two primitive colliders, no scripts and no SDK dependencies.

The front silhouette and decoration were reconstructed from one photograph.
The unseen back is an artistic approximation. This is not a dimensionally
accurate scan. The hexagonal surface relief is a normal map, not printable detail.

FBX: portable mesh in metres; material textures included separately.
GLB: embedded PBR materials and textures, ready for compatible viewers.
BLEND: editable source, packed textures, preview studio and camera.
The studio is excluded from FBX and GLB exports.

VRChat: the model was imported and checked in Unity 2022.3.22f1. No avatar
attachment, SDK upload, or in-client verification is included. Standard materials
target desktop rendering; mobile/Quest materials need a separate conversion.
